# رسوم الوحوش المُصوَّرة

ضع الملفّات هنا باسم هوية البطاقة، ثم شغّل:

```
npm run art:scan
```

الاسم = هوية البطاقة + الامتداد، مثل:

```
mon_fire_lahibo_1.webp     ← لهيبو (المرحلة الأولى)
mon_fire_lahibo_2.webp     ← ضِرغام (المرحلة الثانية)
```

الامتدادات المقبولة: `.webp` ثم `.png` ثم `.jpg` — الأول الموجود يُستعمل.
`webp` مُقدَّم: نفس الجودة بثلث الحجم، و134 صورة تُحسّ في زمن التحميل.

نصوص التوليد الستّون في [`docs/art-prompts.md`](../../../docs/art-prompts.md)،
وتُجدَّد بـ`npm run art:prompts` كلّما تغيّرت الأسماء أو الطُّرُز.

ما لا يوجد له ملفّ يبقى على رسم SVG المولّد — فالخلط مسموح، ولا حاجة
لإكمال الستّين قبل رؤية الأولى.
